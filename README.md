# 订阅账单体检（纯本地 · 单文件）

不用注册、不联网、不接支付的订阅台账：把自动续费的会员录进来，算清每月/每年到底花多少钱、哪些快扣费、哪些早就没用，并生成可直接发给客服的申诉话术。数据只写进本机浏览器的 localStorage。

**整个工具就是一个 `index.html` 文件**（约 53 KB）。样式和脚本都内联在里面，不引用任何外部文件、不引用 CDN、不发任何网络请求，复制这一个文件到任何电脑，双击就能用。

## 一、怎么打开、点哪里、第一步做什么

**怎么打开**

1. 拿到 `index.html` 这**一个**文件（不需要其它配套文件，也不用建文件夹）。
2. 双击它，会用你电脑的默认浏览器打开。
   - 也可以右键 →「打开方式」→ 选 Chrome / Edge / Safari；
   - 或者直接把文件拖进已经打开的浏览器窗口。
3. 不需要安装任何东西，不需要命令行，不需要联网。断网、飞行模式都能正常用。
4. 打开后页面顶部标题是「订阅账单体检」，右边有个 `localStorage` 小标签，说明数据只存本地。

**点哪里**

页面从上到下就 4 块，全在同一个页面里，往下滚就行：

| 区块 | 位置 | 干什么 |
| --- | --- | --- |
| 体检总览 | 第 1 块 | 看每月折算支出、每年总支出、订阅总数；7 天内要扣费的提醒；僵尸订阅浪费了多少钱；支出排行 |
| 订阅台账 | 第 2 块 | 每条订阅一张卡片，右上角「＋ 新增订阅」；卡片上可「编辑 / 生成话术 / 标记很久没用 / 删除」 |
| 申诉话术 | 第 3 块 | 选订阅 → 选模板 → 看话术 → 点「复制话术」 |
| 数据管理 | 第 4 块 | 导出 JSON 备份、导入备份、导出 CSV、载入示例、清空全部 |

**第一步做什么**

第一次打开会自动带 3 条示例数据（云音乐会员、网盘超级会员、健身房月卡），你可以先照着看效果，然后二选一：

- **想先看效果**：什么都不用做，直接往下滚，看「体检总览」和「支出排行」怎么算的。
- **想记自己的账**：点第 2 块右上角的 **「＋ 新增订阅」**，填名称、金额、周期（月付/年付/自定义天数）、下次扣费日期，点「保存」。重复这一步，把你在扣钱的会员都录进来。
- 示例数据不想要了：滚到最下面「数据管理」→ 点 **「清空全部」**（会二次确认）。

> 这 3 条示例数据均为虚构（名称、金额、日期都是编的），只用来演示页面效果，不对应任何真实订阅或扣费记录。

录完 3～5 条之后，回到第 1 块，就能看到你每个月真实在订阅上花多少钱了。

## 二、功能说明

### 1. 订阅台账

每条订阅的字段：

| 字段 | 说明 |
| --- | --- |
| 名称 | 必填，例如「云音乐会员」 |
| 金额 | 必填，这一个周期的价格（元） |
| 周期 | 月付 / 年付 / 自定义天数（填 N 天扣一次） |
| 下次扣费日期 | 必填，用于 7 天提醒和话术里的日期 |
| 类别 | 影音娱乐 / 工具效率 / 云存储 / 学习成长 / 健康运动 / 生活服务 / 其他 |
| 支付渠道 | 微信支付 / 支付宝 / 银行卡 / Apple ID / 应用商店 / 其他 |
| 是否自动续费 | 勾选框，卡片上会显示「自动续费 / 不自动续费」 |
| 备注 | 选填，例如「和室友共用的家庭组」 |

支持新增、编辑、删除（删除有二次确认）。

### 2. 体检总览

- **每月折算支出**：所有订阅按月折算后相加。
- **每年总支出**：每月折算 × 12。
- **订阅总数**：条数。
- **支出排行**：按每月折算金额从高到低，带占比进度条。

折算口径：

```
月付       每月 = 金额
年付       每月 = 金额 ÷ 12
自定义 N 天 每月 = 金额 ÷ (N ÷ 30.44)
每年 = 每月 × 12
```

### 3. 风险标记

- **7 天内即将扣费**：下次扣费日期距今 0～7 天（含今天）的订阅，会在「体检总览」顶部单独列出，同时在台账里置顶并标黄。已过期的会提示「已过期 N 天，记得更新日期」。
- **僵尸订阅**：卡片上点「标记很久没用」，该订阅会汇总到「僵尸订阅」区块，并显示**一年合计浪费金额 = 各僵尸订阅的年金额之和**。

### 4. 申诉话术

选中一条订阅，三个模板任选：

1. **自动续费未提醒 · 要求退款**
2. **误扣申诉**
3. **降价挽留协商**

每条话术都自动带入订阅名、金额、扣费日期、支付渠道，结构统一为：**【争议点】→【我的诉求】→【提交前请核对】**。点「复制话术」，复制到的文字与页面上显示的**完全一致**（同一个字符串，页面显示什么就复制什么）。

> 话术只是模板，发出去之前请自己核对金额和日期，别把 A 平台的账单发给 B 平台。

### 5. 数据管理

- **导出 JSON 备份**：下载 `订阅账单备份_YYYY-MM-DD.json`，含版本号和导出时间。
- **导入 JSON 备份**：选文件 → 确认覆盖 → 恢复。兼容只含 `subscriptions` 数组的裸 JSON。
- **导出 CSV**：`订阅账单_YYYY-MM-DD.csv`，带 UTF-8 BOM，Excel 双击不乱码，含月均/年均列。
- **载入示例**：重新载入 3 条示例（会覆盖当前数据，有确认）。
- **清空全部**：清空所有记录（有确认，建议先导出）。

### 6. 这个工具不做什么

- 不登录任何第三方账号
- 不自动取消订阅（也不碰你的支付账户）
- 不接支付、不代扣款
- 不做云同步、不做多用户

它只是一个本地记账 + 算账 + 生成话术的页面。

## 三、单文件说明

```
subscription-checkup/
├── index.html        整个工具（结构 + 样式 + 脚本全在里面，双击打开）
├── README.md         本文件
└── tests/            开发自测脚本，普通用户可以不看、可以删
    ├── verify.js
    ├── ui-check.js
    ├── verify.log
    └── ui.log
```

`index.html` 内部结构：

| 部分 | 位置 | 内容 |
| --- | --- | --- |
| `<style>` | `<head>` 里，1 段 | 全部样式（约 12.6 KB 字符） |
| `<script>` | `</body>` 前，1 段，无 `src` | 全部逻辑（约 29 KB 字符） |

自包含的硬性约束（每次改完都要成立）：

- 页面里**没有** `<link>`，**没有** `<script src=...>`；
- **没有** `src=` / `href=` 指向任何本地 `.js` / `.css`；
- **没有** 任何 `http://` / `https://` 外链，**没有** CDN；
- **没有** `fetch` / `XMLHttpRequest` / 动态 `import()`；
- 用 `file://` 打开时，浏览器只发出 **1 个请求**——就是 `index.html` 自己。

发给他人的时候，只需要发 `index.html` 一个文件。

## 四、怎么跑校验（可选）

普通用户不需要跑；改代码的人跑这两条：

```bash
# 纯逻辑：把 index.html 里的内联脚本取出来，在 Node 的 vm 沙箱里跑纯函数
node tests/verify.js

# 真浏览器：需要本机已装 Playwright + Chromium
NODE_PATH="$HOME/node_modules" node tests/ui-check.js
```

- `tests/verify.js`：79 项断言（折算口径、排序、7 天边界、僵尸金额、JSON 往返、CSV 转义、话术字段、单文件自包含）。
- `tests/ui-check.js`：53 项断言（自包含与离线、375/414 无溢出、复制一致性、增删改、导出导入往返、刷新持久化、旧版数据兼容）。
- 完整输出留在 `tests/verify.log` 与 `tests/ui.log`。

## 五、数据存在哪、怎么备份

- 存储位置：浏览器 localStorage，键名 `subscription-checkup.v1`。
- 数据结构：`{ version, seeded, subs: [...] }`，单文件版与之前完全一致，**老数据打开新文件直接可读，不迁移、不丢**。
- 作用域：`file://` 协议下所有本地页面共用一个存储区，所以**不要把别的本地页面也起名叫同样的键**。
- 清浏览器缓存 / 换浏览器 / 换电脑 / 用无痕模式，数据都会丢。**重要数据请定期「导出 JSON 备份」**。
- 备份文件是纯文本 JSON，可以直接用记事本打开看。

## 六、已知边界

- 日期按本机时区的「今天」计算，跨时区旅行可能差一天。
- 下次扣费日期不会自动往后滚，扣完一次记得点「编辑」改到下一个周期（页面会对过期日期给出提示）。
- 金额按「元」计，不做多币种换算。
- 年付折算固定用 ÷12，自定义周期固定用 30.44 天/月，不区分大小月。
- 单文件约 53 KB，纯本地存储，不支持多人共享同一份数据（要共享就各自导入同一份 JSON 备份）。
